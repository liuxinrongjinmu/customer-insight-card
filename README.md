# 企业客户信息助手（演示版）

把散落的客户沟通记录（拜访纪要、会议纪要、电话记录、邮件）变成一张**能点回原文**的客户认知卡：
这个客户是谁、过去发生过什么、现在最该做什么。

三条硬约束，也是这个项目全部的设计取舍：

1. **每句话都能溯源**。卡片上的每一条事实都带 `source_span`，必须是原文的连续子串；
   指不回原文的，在入库前就整条拒收。
2. **零模型的部分尽量大**。归并、冲突判定、保鲜期、缺口检测、建议、简报全部是规则，
   不调模型——同样的输入永远同样的输出，能离线复现。
3. **说清自己不知道什么**。卡片上有「空白项」，区分三种空：没人写过 / 写过但过期了 /
   本系统结构上产不出。说成同一种，用户会把「系统产不出」读成「这个客户没有风险」。

零第三方依赖，只用 Python 标准库（3.9+）。状态落本地 SQLite 单文件，进程退出不丢。

## 快速开始

### 1. 先跑起来（不需要任何 API key）

```bash
git clone https://github.com/liuxinrongjinmu/customer-insight-card.git
cd customer-insight-card
python3 demo/serve.py --offline --allow-reset
```

打开 <http://127.0.0.1:8000/>。`--offline` 表示只回放内置示例的抽取缓存、不联网；
39 个预置客户、65 篇记录、139 条事实是随代码一起带过来的种子数据，启动即灌库。

> 首次启动会在 `demo/cache/` 下建一个 SQLite 文件；删掉它等于清空，下次启动重新灌种子。

### 2. 接上真模型（可选）

复制 `.env.example` 为 `.env`，填一个厂商的 key（DeepSeek / 智谱 / 通义千问，都是 OpenAI 兼容接口）：

```bash
cp .env.example .env      # 然后编辑 .env，填 <PREFIX>_API_KEY
python3 demo/serve.py --allow-reset
```

页面右上角会实时标注当前是「真实模型」还是「离线回放」——这一条本身是刻意设计的：
演示时最怕的是观众以为在看实时推理，其实在看三小时前的缓存。

### 3. 自检（可选）

```bash
python3 demo/smoke.py         # 55 条接口用例：正常 / 异常 / 边界 / 落盘 / 归属
python3 demo/ui_check.py      # 219 条界面断言（需 node）
python3 demo/tour.py          # 七幕演示提词器：每幕的数字现场从接口取
```

## 几个可以直接看的点

- **溯源**：随便点一条事实，看它右边「原文」那半句，再翻记录核对——逐字对得上。
- **冲突**：恒远重工那张卡上有两条需求说两个降本比例，系统不挑一个信，并排放着标红。
- **空白**：星海电子只有一篇记录，风险信号那栏说「本系统不产出（变化要至少两篇才比得出来）」，
  不是「无有效记录」——这两句对用户意味着完全相反的事。
- **模型猜的变化不上卡**：模型读出来的「变化」要用规则的判据量一遍它自己的证据，
  量不出来就不上卡，但卡面会写明「另有 N 条模型推测未计入」，不偷偷改口径。

## 已知边界（这个版本没有做什么）

- **没有身份认证**。`--user` 是启动参数，同机任何人都能换个身份起服务。归属隔离只回答
  「这条数据是谁的」，不回答「你是谁」。
- **没有多进程支持**。只验过单进程多线程；多个 worker 并发写同一个库会不会丢，没解。
- **抽取质量的样本内数字**：50 篇金标准上事实级 F1 0.670、封闭集字段 F1 0.544（门槛 0.85，**未达到**）。
  这些是样本内数字，不能外推。
- **外部效度未验证**。脏数据、边界用例都是自造的，只能证明「同样的脏输入不崩、不编、不藏」，
  不能证明真实销售的话也长这样。
